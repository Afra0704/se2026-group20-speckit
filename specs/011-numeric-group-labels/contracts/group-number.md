# 加入與組別顯示契約草案

現有加入請求的 `group_name` 維持字串。前後端均先去除前後空白，再驗證半形數字 1–999。#16／#17 的本機介面採用 `INVALID_GROUP_NUMBER`（HTTP 400）。無效值保留在欄位，使用紅字及 aria-invalid／aria-describedby，修正後可重送。後端拒絕後不改原資格。

合法組號的共用顯示為「第 N 組」。師生結果與 001 回填依原課堂的可信組別映射顯示，不依畫面文字查找資料。

#19 的回填頁以作業或預覽所屬的原活動定位原課堂，再以快照記錄的勝組 ID 解析標籤。顯示層與快照欄位分開，保留既有快照、結果版本與作業識別。
