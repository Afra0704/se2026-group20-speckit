# Phase 1 資料模型

| 實體 | 欄位 | 約束 |
| --- | --- | --- |
| 課程 | `course_id`、管理教師、名稱、建立時間 | 教師管理自己的課程。名稱供顯示。 |
| 課堂 | `classroom_id`、`course_id`、名稱、唯一加入碼、`OPEN/CLOSED`、目前活動、`state_version`、開課及關課時間 | 目前活動必須屬同一課堂，初始為空。發布階段或切換時遞增版本。已結束不可重開。 |
| 課堂組別 | `classroom_id`、`group_id`、組名 | 空白拒絕。同堂整理後的相同名稱唯一，不同課堂分離。 |
| 加入證明與授權 | `membership_id`、課堂、組別、瀏覽器證明摘要、撤銷／期限及短期授權 | 只有進行中的課堂可建立加入。結束後原瀏覽器可恢復唯讀結果授權；不得切換組別。 |
| 活動 | `activity_id`、課堂、名稱、時間、階段、`import_id/import_version`、有序題目 | 開啟只允許本堂沒有其他搶答中的活動。以同一交易檢查，並以資料庫唯一性保護每課堂最多一筆 `LIVE`。 |
| 講義版本／001 | 課程、`import_id/import_version`、名稱、可用性、題目與來源映射 | 002 只使用屬同課程的指定版本。001 管理 Sheets 位置與存取授權。 |
| 作答與結果／003 | 活動、課堂組別、題目、完整答案與結果版本 | 同一份講義建立的活動各自保存。只有已結束且已結算的活動可提供回填快照。 |

狀態順序為課堂 `OPEN → CLOSED`，活動 `PREPARING → LIVE → CLOSED`。關課後不得再啟動任何活動。歷史與結算查詢仍可經角色授權進行。
