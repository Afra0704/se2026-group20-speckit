# 003 驗證指南

正常啟動會載入 003 正式受理、作答進度及結算 provider。每次驗證記錄日期、操作者、commit、預期與實際結果。實際驗證狀態見 [validation.md](validation.md)。

## 本機準備

從 repository 根目錄執行。採用 [008 工作區設定指南](../008-teacher-course-workspace/quickstart.md) 已可用的 Google Web client、Fernet key 和相容 DB。用既有講義或貼連結即可驗證，保留原本登入設定與資料；測試回填時用有填寫權限的 Google Sheets 副本。正式啟動前停掉舊服務並沿用私有環境變數。

```powershell
uv sync --locked
uv run flask --app guided_notes:create_app init-db
uv run flask --app guided_notes:create_app run --host 127.0.0.1 --port 5000
```

## 自動驗證

```powershell
uv run pytest tests -q --tb=short
$jsTests = @(Get-ChildItem -LiteralPath tests -Filter '*.test.cjs' -File | ForEach-Object FullName)
node --test @jsTests
```

以暫存 SQLite 與受控 Sheets 執行，整合測試用正式 003 provider。用兩連線與同步屏障控制「送答提交先」和「活動結束提交先」兩種順序，涵蓋關課隱含結束，且同時接受的兩組有穩定順位。注入結算中斷並重啟，驗證待辦恢復、無半份快照、結果只發布一次。回填整合應使用正式提交與結算，Sheets 層保持替代來源，並驗證實際寫入清單與讀回。

## 教師與兩組學生

使用一位教師及 A、B 兩組各自的瀏覽器工作階段。每個排序情境用新活動重跑。

| 操作 | 預期 |
| --- | --- |
| 建立含單題與題組的活動 | 準備中兩組可讀全文，送答拒絕。LIVE 只接受完整小題，不接受空白、漏答、重複或未知小題。 |
| A 先交、B 後交，A 主動再交一次 | 教師 LIVE 看見兩組已答。結算為 B 第一、A 第二；A 只保留最新答案。 |
| A 受理後回應遺失、B 交、A 重試同一次送答 | 回原受理結果，A 第一、B 第二。同 key 改內容拒絕；重試已被取代的舊收據不更換目前有效答案。 |
| A 送出後回覆不明，在同一分頁重整 | 恢復原活動、組別與合法資格時，可手動以原 key 與答案重試，順位不變。重整不自動送答；活動或組別不符時不顯示重試。 |
| 結束活動，暫不關課（D22） | 新瀏覽器合法加入同堂後，也能從歷史清單及直接請求查看該場已結算結果。學生只看本組和勝組，不能查其他非勝組資料或其他課堂。 |
| 結束後再提交或切下一場 | 舊活動拒絕新提交，新活動排行獨立。 |
| 關課後查看歷史 | 原瀏覽器有合法證明時可恢復結果；新瀏覽器無原證明時，不能用同名組別重新加入或讀取結果。 |
| 從準備中結束，以及中斷後重啟 | 前者每題明確無勝組，後者能取回同一結果版本。未結束、待結算、已結算與舊活動沒有正式資料可區分。 |
| 結算後在 001 建立預覽並同意回填 | 每題只取勝組完整小題；無勝組的題目不覆蓋。回讀逐格原字串及非目標內容，另用欄列與題數不同的講義副本再驗一次。 |
| 在活動建立後移除講義，或回填前變更副本 | 活動仍能按固定題目結算。含整數 `contract_version: 1` 的快照可用活動原歷史清單驗證；001 按既有來源檢核作業，失敗或需恢復時保留原勝組和結果版本。 |

驗證記錄須區分自動受控與真實瀏覽器／Google 驗收。正式 Sheets 驗收依 [001 指南](../001-guided-notes/quickstart.md) 執行來源變動、回讀與恢復，並保留非目標資料與格式。
