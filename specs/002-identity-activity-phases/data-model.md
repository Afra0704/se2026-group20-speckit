# Phase 1 資料模型：002 身分與活動階段

| 實體／擁有模組 | 欄位與關聯 | 約束 |
| --- | --- | --- |
| 清單版本／001 | `list_id`、`version`、可用性、使用範圍、有序題目。每題含 `question_id`、顯示題號、位置及可選顯示文字。 | 清單與版本組合唯一。已交付的版本不可變，每版題目 ID 和位置各自唯一，至少一題。來源格位與憑證留在 001。 |
| 活動／002 | `activity_id`、管理教師識別、活動碼、`list_id`、`version`、`phase`、`phase_version`。 | 活動識別、活動碼各自唯一。清單參考建立後固定。階段版本隨成功轉換遞增。 |
| 活動題目／002 | `activity_id`、`question_id`、顯示題號、位置、可選顯示文字。 | 複製自指定清單版本。每活動題目及位置各自唯一。顯示題號不當關聯鍵。 |
| 教師帳號／002 | `teacher_id`、登入名稱、密碼雜湊、帳號狀態。 | 登入名稱唯一。管理操作要求帳號有效且是該活動的管理教師。 |
| 活動組別／002 | `activity_id`、`group_id`、自填組別名稱與去除首尾空白後的名稱。 | 組別識別在活動內唯一。同一活動內相同的整理後名稱對應同一組別，空白名稱拒絕。 |
| 原加入紀錄／002 | `join_id`、`activity_id`、`group_id`、瀏覽器恢復憑證摘要、建立與撤銷狀態。 | 僅在結束前成功加入時產生。結果恢復要求仍有效且綁定原活動與組別的原加入證明，恢復不建立新的加入紀錄。 |
| 授權／002 | 伺服器端工作階段識別、教師 ID 或原加入紀錄、權限範圍、到期與撤銷狀態。 | 教師、學生權限分開。由原加入紀錄恢復的已結束授權只可讀取該活動的允許資料和結果。 |
| 作答情境／002 提供 003 | 活動、組別、有效授權、階段與版本、清單版本、有效題目。 | 同一寫入交易內核對，以活動題目及活動組別關聯。無法由瀏覽器指定權威欄位。 |
| 已受理答案與結果／003 | `activity_id`、`question_id`、`group_id`、答案或結果資料、結算狀態。 | 僅成功提交交易的答案可納入結算。順位與重送的詳細約束待 D01／D02。 |

## 狀態轉換和資料一致性

| 原階段 | 操作 | 提交交易後 |
| --- | --- | --- |
| `PREPARING` | 管理教師開啟 | `LIVE` |
| `LIVE` | 管理教師結束 | `CLOSED` |
| 其他組合 | 開啟或結束 | 拒絕，保留原階段與版本 |

加入與操作均以交易中最新狀態判定。準備中和搶答中允許新加入，只有搶答中允許提交。結束後原組別驗證是對既有紀錄重新授權。結算狀態與活動階段分離，結算未就緒時仍顯示已結束。
