# Guided Notes Format Contract v1

適用於 [spec.md](../spec.md) FR-002、FR-013、FR-014，將可見範本結構轉為主題號及有序作答項目。
此為根據截圖制定的辨識設計，完整 Google GridData／merges 仍需實測。

## 輸入與表頭

1. 只接受有效 Google Sheets spreadsheetId；worksheet 以 numeric sheetId 選定。URL 可含 gid 作預選，教師仍看到選定名稱。
2. 讀取 GridData 的起始 row／column 索引、userEnteredValue、formattedValue 與 `sheets[].merges`。不能將 API 省略的尾端空白視為不存在的答案格。
3. 用去除前後空白的文字找同一列「題號」「題目」「作答」。每個表頭可跨欄合併，其範圍界定三個欄區；標題列與裝飾列不算表頭。
4. 單一候選表頭才繼續。缺少、重複或欄區交疊時定位回報 HEADER_MISSING／HEADER_AMBIGUOUS。
5. 合併範圍以 anchor＋span 正規化。Google GridRange 是零起算、結束索引不含，單格 range 也使用相同表示。

## 主題號及題組

- 題號欄區內正整數值／純數字字串視為主題號 anchor，正規化為十進位字串。兩個 anchor 正規化後相同時 DUPLICATE_QUESTION。
- 主題號跨列合併時，該 span 界定它的小題範圍；未合併時只涵蓋該列。不得把下一列空白題號 forward-fill 為題組。
- 在該範圍的作答欄區找完整匹配 `(正整數)` 的小題標號，接受半形／全形括號及括號內前後空白，保留原標號文字。
- 有小題標號時，每個標號對應同列右方且在作答表頭欄區內的唯一答案區。標號為合併格時從其 span 右界開始找。
- 無小題標號時，需存在與主題號範圍匹配的唯一答案區，形成 single。題組至少兩個小題，各序號唯一且順序依版面自上而下。
- 題目欄區合併範圍只供小題定位與語意核對，題目文字不必流向學生端。題目敘述可跨欄／列，需與作答項目一對一或可唯一辨識。
- 不從顏色、邊框或相鄰列猜測歸屬。無法唯一判定時顯示位置及原因，由來源修正後重讀。

## 答案範圍

- 答案可以是真正空白、既有文字或公式，不以「有值才存在」判定答案區。
- 在候選答案欄區中，唯一覆蓋預期區域的合併格形成 answer_range；單一未合併格也有效。多個獨立候選格則 ANSWER_AMBIGUOUS。
- 跨欄合併答案寫到其左上角 anchor。若答案格跨不同小題或不同主題號，回報 ANSWER_OVERLAP。
- 子題標號、表頭、題目及分隔列不作為答案目標。寫入不得 merge／unmerge 或改格式。
- 源表只移位置、換欄寬或工作表改名後，重新讀取 ranges、以主題號與小題識別配對，再重新預覽。

## 計數及範例

主題號 1 有 1(1)、1(2)，主題號 2 為單題，輸出 question_count=2、submission_unit_count=2、answer_item_count=3。
主題號 1 的所有小題答案一次提交且共用一個勝組，回填各小題的答案錨點。

合成輸入須至少覆蓋以下布局。

| 案例 | 結構 | 預期 |
| --- | --- | --- |
| 單題 | 作答表頭跨兩欄，下方答案跨同兩欄 | 一題一格，目標為答案 merge anchor |
| 題組 | 題號跨兩列，左側 (1)、(2)，右側各有空白答案 | 一題兩項，兩個不同答案 anchor |
| 混合 | 題組後有空白分隔列及單題 | 分隔列不增加題數 |
| 移動 | 整張表往右／下移動並變更答案合併寬度 | 題目及小題身份相同，位置重新辨識 |
| 歧義 | 同主題號重複子題號、答案跨小題或兩個候選答案格 | 定位錯誤，無法確認匯入 |

## 格式錯誤

回傳 error code、工作表 id、主題號／小題標號（若可辨識）、問題範圍與可修正原因。
多個錯誤可一起列出，任何影響身份或答案唯一性的錯誤都禁止發布 catalog。
格式規則及子題序號正規化須由 001／002／003 共用同一契約；原始座標留在教師來源對應中。
