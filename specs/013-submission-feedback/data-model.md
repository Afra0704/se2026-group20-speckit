# 資料模型

| 實體 | 欄位與關係 |
|---|---|
| 本題作用域 | 固定課堂 ID、活動 ID、組別 ID、題目 ID、#17 文件作用域。每個作用域最多一個未決操作。 |
| 表單欄位 | 原始文字、已知小題 ID、局部錯誤。驗空使用暫時判斷值，新的有效操作保存原文。 |
| 未決操作 | 既有 UUID 與原始提交內容。本頁短暫的嘗試識別用於拒絕晚回；持久格式相容 #17 的既有記錄。 |
| 本題回饋 | 目前狀態、是否已有可確認的受理、欄位提示及目前嘗試。畫面重建時只讀取目前作用域，上一活動的提示不延伸。 |
| 正式受理紀錄 | 003 的受理序列及同組重送記錄，原樣重試查回既有結果。無額外寫入。 |

狀態依 [送答契約](contracts/submission-feedback.md) 轉移。已知未決操作出現在已驗證的同頁重整時，可用原操作回到結果未知。複製頁開新作用域。明確撤回本頁後，舊回覆不得重新寫入本地操作或畫面。

重送衝突可在既有未決資料加選填標記，以同一文件作用域恢復「無法核對原送答」及不可重試狀態。缺少標記的 #17 記錄沿用一般結果未知的行為。

未決鍵仍由課堂、活動、組別、題目與文件作用域依原順序序列化，不改前綴或 UUID。送出嘗試用記憶體識別，畫面失效後不更新舊畫面；清理或標記未決操作前仍比對最新嘗試與原 UUID。
