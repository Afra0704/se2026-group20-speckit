# 驗收指南

以備份或測試用 SQLite、Sheets 副本及 README 的本機環境啟動。使用一位教師與至少兩組學生，B 需三個獨立瀏覽器環境。

```powershell
.venv\Scripts\python.exe -m pytest tests/unit tests/contract tests/integration -q
node --test tests/*.test.cjs
.venv\Scripts\python.exe -m flask --app guided_notes:create_app run --host 127.0.0.1 --port 5000
```

1. A：送出空白、隨機文字、外部 URL、不支援的 Sheets URL，再修正並完成授權、選頁、預覽及匯入。另驗證權限不足與暫時讀取失敗。
2. C：從準備中及搶答中結束活動，觀察結算中、自動發布、無正式資料與重試。從 /student 加入，驗證師生權限、題組格式、OPEN 的晚加入歷史、本場自動結果晚到時仍保留手動選取的歷史畫面，以及下一活動出現時恢復主畫面並忽略舊成功／失敗回應。延遲歷史請求，同時讓教師整堂關閉，學生應立即依同步狀態清除內容；測試原瀏覽器重開仍不能看 CLOSED 結果，教師仍能查歷史及回填。記錄活動結束至畫面切換的時間。
3. B：以兩組 2＋1 身分驗證多頁、重整、重試、關最後頁、斷線、背景與重連。量測加入／重連 5 秒及最後頁失聯 5 秒（最新 5／5 門檻）兩項目標，驗證切換活動、不同課堂、失敗提示及關課。核對在線變動前後正式結果一致。
4. 整體交付核對兩份不同題數或配置的講義匯入及回填證據，必要時以測試副本補驗。
5. 記錄日期、執行者、版本、情境、預期、實際及延遲。人工及自動驗證各自記錄。
