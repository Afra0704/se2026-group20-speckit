# 設計研究

- **A 欄位錯誤**。匯入表單的 required 與 URL 原生驗證可能在 submit 前攔截，需在欄位 invalid 時顯示鄰接提示。伺服器既有 parse_sheets_url 仍決定支援來源。依實際後端錯誤分類呈現，保留 OAuth 與既有匯入狀態。
- **C 結果選取**。009 學生端已由 student-room.js 處理固定課堂、世代與結果選取；ea5efbb 將結果查詢與狀態輪詢分開，並隔離過期錯誤。以此擴充自動與手動結果目標，下一活動優先恢復課堂主畫面，整堂 CLOSED 取消在途請求與清內容。教師沿用 classroom.js 的授權投影及教師進度。
- **B 去重風險**。009 現有 join 仍會新增 membership，單純計數 membership 無法符合重試去重。先驗證既有課堂資格，再由簽章 session 的瀏覽器身分計數；每頁只更新自己的存活狀態。伺服器逾時負責辨識無通知離線，並須實測背景頁限制。採 3 秒心跳與 25 秒逾時，留出教師輪詢時間；5／30 秒為已回報確認的端到端驗收目標。瀏覽器凍結背景頁會停止訊號，這項限制需在真人驗收中記錄。

2026-11-27 使用者改為 5／5 秒目標：每秒心跳、4 秒 TTL 預留教師每秒輪詢時間；online 立即重送心跳，不等待間隔，且新 generation 不被舊請求阻擋。此為正常排程及網路環境的驗收目標，背景／凍結造成的誤判需獨立驗證，不以延長離線門檻掩蓋。
