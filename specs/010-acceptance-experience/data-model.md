# 資料模型

- **匯入欄位狀態**。保留原始輸入，提示具原因與修正文字。空白或無效來源對應欄位，讀取與授權失敗對應操作。每次嘗試重設不相干的提示，成功清除欄位錯誤。
- **結果檢視**。保留固定內部課堂 ID、課堂世代、當前活動 ID、查閱目標 ID 及選取版本。整堂 CLOSED 使學生結果檢視終止並清除；教師投影仍可正常查詢。結果狀態為 active、pending、settled、unavailable，以及本次讀取失敗。切換目標撤銷前一版本。結果資料沿用 003 結算快照與角色投影。
- **在線參與**。一堂課下同組可有多個受授權參與身分；單一身分下可有多個頁面，每頁具伺服器記錄的到期時間。瀏覽器鍵由既有簽章 session 的 CSRF 身分雜湊取得，頁面 ID 由瀏覽器各自產生。新增獨立資料表，既有資料庫升級可重跑。聚合只計具有至少一個未逾時頁面的身分，沒有在線者仍保留組別。關課後終止在線更新。加入碼釋放與重用不改變任何在線身分紀錄的課堂歸屬。與正式答題及回填快照分開儲存。
