# 012 驗收指南

使用空白暫存資料庫，教師登入、測試講義及原有本機啟動方式見 README。準備一個教師及至少兩組學生；以同一瀏覽器的兩個分頁測隔離。

```powershell
node --test tests/*.test.cjs
uv run --locked --python 3.13 python -m pytest tests/contract tests/integration -q
```

1. 建立甲堂、乙堂。用同一瀏覽器分頁 A 加入甲堂第 1 組，分頁 B 加入乙堂第 2 組。各自重整、斷線重連及查看結果，另一頁資格保持有效。
2. 複製 A，預期新頁直達甲堂第 1 組，教師仍看到一人在線。再測複製後原頁立即關閉的情況。在複製頁重新加入並確認，原頁保持資格。測同堂仍有原組有效頁時，異組請求被拒；關閉原堂所有有效頁並逾時後，可換組。
3. 讓學生留下草稿或受控的未決答題。取消重加入保留操作；確認時只清本頁。送答晚回不得污染新頁，已受理資料、idempotency 與順位保持。
4. 以測試時鐘驗收短效資格到期、仍有效的原頁恢復、恢復失效、錯堂、偽造及 CSRF。教師整堂關閉時，學生停止看題目與歷史。重用原碼的新堂與舊資格隔離，教師仍能查原歷史及回填。
5. 記錄版本、操作者、日期、預期與實際行為。使用真實瀏覽器測複製、關頁及在線更新延遲，人工與受控測試分開記錄。
