# 012 設計研究

## 分頁識別與恢復

採「瀏覽器綁定、分頁查詢索引、短效文件資格」三層。瀏覽器綁定由同來源 HttpOnly cookie 提供。sessionStorage 存每頁可恢復的索引，索引只供受限的恢復端點解析；還須驗證 cookie、CSRF、原堂原組及期限。每份文件在記憶體取得自己的短效資格。恢復會發新的分頁索引與資格，複製頁保有原堂原組，新舊頁撤回各自的資格。只開原網址的全新分頁若沒有恢復索引，顯示重新加入。檢查瀏覽器資料被清除或停用時的失效行為。

sessionStorage 的初始內容可能被複製，採用它作為可恢復索引，授權與在線計數仍由伺服器判斷。瀏覽器不同版本的「複製分頁」行為納入人工驗收。 [HTML Standard](https://html.spec.whatwg.org/multipage/webstorage.html#the-sessionstorage-attribute)

## 同堂單組與競態

010 的教師列表去重本身無法拒絕不同組。加入、恢復與組別切換使用同一寫入交易，並在發送首個心跳前原子建立在線保留。最後頁失聯使用既有 4 秒逾時判定。若同堂已改組，增加該瀏覽器的課堂世代，使舊組的恢復、狀態、結果、送答與心跳請求失效。心跳或頁面離線只影響該頁的在線狀態；明確重新加入撤回該頁資格。

## 威脅模型與送答

網址、日誌與 localStorage 排除任何資格。索引及記憶體資格限制在對應瀏覽器、課堂、組別、分頁世代和期限。恢復端點需要 CSRF，秘密與索引不寫入應用記錄。直接請求仍由伺服器覆核，不依賴畫面選擇或群組名稱。跨堂誤用、過期、偽造、關課與跨來源請求涵蓋契約測試。既有同來源程式碼屬信任邊界；本機資料遭清除時要求重新加入。

送答保留原作用域、key 與 payload。重整可恢復原頁的明確重試。複製頁開始新的本機操作作用域，未決操作的歸屬由伺服器核對的前一份文件及前端交接資訊判斷；無法判明時不自動送出或替換原 key，提示回原頁核對。#18 負責詳盡的送答狀態文案。

## 重整與複製的分流驗證

每次文件載入均產生新的文件 ID，恢復資格與前次文件獨立。頁面重整且需要承接未決操作時，必須同時有瀏覽器回報的 reload 類型，以及上一個文件在離開時留下、由伺服器核對且可消費一次的交接識別。交接只允許繼續同一作用域，仍由 UI 明確重試。Navigation Timing 是輔助訊號，只會區分導航類型。瀏覽器複製分頁的差異必須以實機確認。 [W3C Navigation Timing 定義](https://www.w3.org/TR/navigation-timing-2/#sec-performance-navigation-timing)

複製頁、直接打開網址及無法確認交接的頁面，均建立新的操作作用域。複製頁有可用的瀏覽器與恢復索引時仍進入原堂原組，即使原頁在新頁完成恢復前關閉。複製頁不能沿用可能由瀏覽器複製的本機未決答案。離線時若未能送達交接，原堂原組仍可恢復，但舊 pending 先保留並提示核對，不自動重送或重新產生 key。對已用交接識別收到相同 `request_id` 的重試維持原決定；另一個請求發新作用域。測試應證明主流目標瀏覽器下複製不會被此條件誤判為重整。

BFCache 返回優先使用本文件記憶體中的識別並重新驗權；已撤回或已換組不得復用。普通關頁與頁面暫停都不撤回恢復權。接受既有課堂資料庫與教師／舊獨立活動授權；012 學生頁啟用新協定後不回退到同瀏覽器的共享課堂 grant。升級前已開啟且無本頁索引的課堂頁提示重新加入，舊已受理答案仍保留。
