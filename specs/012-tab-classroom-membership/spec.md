# 012 學生分頁資格與重新加入

2026-11-27（台北時間）。雙組規則已確認，新版圖表已由組員複核；以 master `e9a29c7` 為基底。來源 [Issue #17](https://github.com/Afra0704/se2026-group20-speckit/issues/17)。

## 使用者情境與驗收

- 同一瀏覽器的兩頁加入不同課堂，重新整理、斷線恢復及切換其中一頁時，另一頁仍保持原課堂及原組別。
- 重新加入前若有草稿或等待重試的送答，學生先看到提示。取消保留現況；確認後只清本頁資格與本機操作狀態，返回空白加入頁。介面說明回覆不明的答案可能已受理。
- 教師關課後，原頁顯示課堂終止，學生不能讀已關閉課堂的內容。重用課堂碼建立新堂時，舊頁與舊資格仍綁原堂。

## 功能需求

- FR-012-01。每頁的課堂、原組別與授權獨立驗證，重新整理與重連依定案規則恢復。教師授權不受影響。
- FR-012-02。重新加入僅清本頁草稿、未決重試及資格；既有正式答案、順位、原組和教師歷史保留。較早請求的回覆不可更新已換資格的頁面。
- FR-012-03。保留 009 的課堂 ID 與 CLOSED 限制，維持 010 的在線去重。資格通道需經威脅模型檢查；避免跨堂長效秘密進入網址、日誌或無限制的前端儲存。
- FR-012-04。同一瀏覽器在同一開放課堂只能有一個有效組別。其他分頁嘗試加入不同組時，拒絕新請求並保留原分頁。不同課堂的分頁可獨立加入。最後一個有效頁面失聯並達 010 在線逾時後，可重新加入同堂其他組。
- FR-012-05。複製有有效資格的開放課堂分頁時，新頁直接沿用原課堂與原組別，取得獨立分頁資格，不需重新輸入課堂碼與組號。原頁維持可用，同一瀏覽器在該堂只計一人在線。原分頁重整或重連時，若可用的原頁恢復資格仍有效、課堂仍開放且組別仍可用，才自動恢復原堂原組；恢復資格已失效時提示重新加入。已確認關課時走既有終止畫面。

## 驗收條件

- SC-012-01。以一位教師與兩組學生測雙堂、重整、重連、取消重加入與確認重加入。核對輸入空白及其他頁維持原組。
- SC-012-02。核對錯堂、錯組、過期、偽造資格、CSRF、關堂、碼重用及晚到回應。比對正式作答、教師回填與在線數。
- SC-012-03。以同瀏覽器兩頁測同堂異組被拒、跨堂加入、複製有效分頁後直接進入原堂原組、有效原頁重連、失效後重新加入及最後頁逾時後換組。複製後兩頁合計一人在線，任一頁重新加入不清除另一頁資格。核對新組不承接已受理答案或順位。

## 待釐清與相依

- 2026-11-27，使用者回報 SpecKit／OpenSpec 兩組已確認同堂單一組別、複製有效分頁沿用原堂原組、原頁有有效資格時自動恢復，以及最後有效頁逾時後可換組。新版圖表組員複核已記錄。
- #17 的換組限制與 #18 的未決操作提示依共用契約處理。原組別仍有其他有效分頁時，單頁重新加入不會解除其他分頁的組別。
- 與 #16 對齊錯誤碼及原資格保留，與 #18 對齊待重試答案與晚到回應。可先審查需求及安全模型，共同行為需雙組確認。

## #16 加入介面交接

加入及重新加入表單沿用字串 `group_name`。無效組號的欄位錯誤為 `INVALID_GROUP_NUMBER`（HTTP 400），保留原輸入及該頁當時仍持有的有效資格。明確確認離開時的本頁清理仍依 FR-012-02。詳見 [011 契約](https://github.com/Afra0704/se2026-group20-speckit/blob/e4c3b00f427ac9f8306c1a1145c68e21d655473c/specs/011-numeric-group-labels/contracts/group-number.md)。PR #22 尚未合併時先依此契約規劃，接線前核對合併版本。
