# 012 資料模型

| 實體 | 身分與狀態 |
| --- | --- |
| 瀏覽器 | 專用 HttpOnly cookie 的伺服器綁定。與教師登入 grant 分開。資料表僅保存伺服器驗證所需衍生值。 |
| 瀏覽器課堂組別 | 瀏覽器 × 固定課堂 ID 唯一；包含目前組別 ID 與世代。只允許在沒有其他有效分頁時換組，換組加一世代。 |
| 分頁資格 | 指向瀏覽器、固定課堂、原 membership／group 與組別世代。具有恢復索引、短效文件資格、到期與撤回狀態。每次載入或複製取得獨立文件資格。 |
| 文件交接 | 瀏覽器、課堂及來源文件下的一次性記錄。雜湊保存 120 秒有效交接識別，使用後記錄已消費，重試則沿用原請求決定。 |
| 在線頁面 | 採 010 的固定課堂／瀏覽器／分頁計數模型。伺服器驗權後更新 TTL，教師按瀏覽器去重。 |
| 本頁未決操作 | 綁課堂、活動、組別、題目與本頁作用域；保留原 key 和 payload。確認重整時沿用本頁作用域，複製頁另建作用域，重新加入只清目前作用域。既有正式答案、快照及排名仍由 003 管理。 |

獨立資料表交易式初始化並可重跑，既有課堂、組別、grant、回填與歷史保留。課堂 CLOSED 為終態。同一瀏覽器改組後，舊組世代終止。明確離開只撤回目前頁，失聯只移除在線判定。
